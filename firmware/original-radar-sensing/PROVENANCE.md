# 0.3.2-rc1 provenance

The continuous-session extension was compiled and linked locally with installed official Windows SDK 03.06.02.00-LTS, ARM CGT 16.9.6.LTS, SYS/BIOS 6.73.01.01 and XDCtools 3.50.08.24. Exact tool roots and commands are in WINDOWS_BUILD.md. Unmodified official Windows ImageCreator tools produced the separately named candidate BIN; an independent appended CRC32 comparison and structural ELF checks passed. No board, flasher or serial port was accessed. Current artifact identity belongs to `build/0.3.2-rc1/`; the original root BIN and RELEASE_MANIFEST remain 0.3.1-rc1 and are not relabeled.

Changes are original application/config/lease/timestamp orchestration. Pinned TI `rl_sensor.h` documents `numFrames=0` as recurring frames until Stop. The underlying chirp/frame profile, AOP feed correction, calibration trust flags, no-RF pairing and explicit Start gates are retained. A rolling 5000 ms control lease requires a matching nonce/config/session keepalive approximately every 1000 ms; malformed, stale or expired tuples cannot renew. Session elapsed timestamps use 64-bit extension of the 1 ms clock. Source identity generation uses portable manifest path names and LF output while hashing actual input bytes.

This release retains the project's independently authored radar acquisition, DSP, spatial estimator and no-RF boot self-test. The inherited `src/record_transport.c/.h` guard is now applied independently to both UARTs. New `src/link_session.c/.h` and the application adapter implement strict nonce correlation, generation/session binding and one-shot Start permission; no TI driver source was copied or modified. The adapter uses the pinned SDK's public register definitions and UART instance mapping. No TI demo processing/tracking/classifier was substituted.

Original licenses and third-party notices are retained byte-for-byte. Earlier release provenance is preserved in HISTORY. Vendor SDK/compiler/compatibility tools are external prerequisites, not redistributed in this package.

Build versions: TI mmWave SDK 03.06.02.00-LTS, ARM CGT 16.9.6.LTS, SYS/BIOS 6.73.01.01, XDC 3.50.08.24. Official SDK installer SHA-256: `904ba6555e2c6bf6a3256c35e9b4155e6b1d43eaf88a2df025b7fea69d1fd674`. Legacy vendor executable bytes remain unmodified and are launched through official Debian QEMU 10.0.13/libc 6-i 386 compatibility; XDC runs natively. Official Debian Mono 6.12.0.199 runs the vendor out 2 rprc packaging utility.

The inherited spatial correction was previously checked by rebuilding the entire original v0.2.0 BIN byte-for-byte and executing TI-generated synthetic tests in ARM instruction emulation. The new transport guard is tested with an explicit pending-TD-overwrite model, including actual application adapters/status/ACK/pair commands and frame serializer, and the final compiled guard and link-session objects is also executed in ARM emulation. Neither simulated peripheral state nor instruction emulation proves physical UART behavior.

This public distribution includes source, the new BIN, configs, tests, notices, relative-path manifests and sanitized aggregate validation. It excludes user capture data, ELF/map/link XML, raw logs, installed toolchains and private workspace identifiers. `BUILD_IDENTITY.json` identifies source/config plus pinned tool versions; `RELEASE_MANIFEST.json` identifies exact distributed bytes.

The v0.3.1 candidate adds an independently authored AOP configuration initializer using only the documented physical receiver feed-polarity facts. TI SWRU 546 E Figure 4-8 specifies alternating antenna groups 180 degrees apart; pinned SDK ti/demo/xwr 64 xx/mmw/profiles/profile_3 d_aop.cfg line 55 provides the equivalent(+1,−1,+1,−1) physical-RX convention. No TI demo processing code is imported. Private input-derived replay cases remain outside the source/public package; public regression cases are analytic synthetic plane waves.
