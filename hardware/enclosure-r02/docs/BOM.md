All printed geometry uses millimetres. Quantities below are installed quantities, not the number of files.

| Part | Description | Quantity |
|---|---|---:|
| 01 | Integrated main shell | 1 |
| 02 | Removable rear cover | 1 |

Total: 19 installed pieces, seven unique types. Optional C01–C03 are tripod-thread radial-clearance coupons (0.15, 0.25 and 0.35 mm); C04 is a common-screw fit coupon. They are not installed.

External items: actual TI IWR6843AOPEVM Rev G radar board, actual Logitech C920e, existing tripod hardware, suitable cables, measured housing-safe compliant pads/shims, compatible sealing/strain-relief materials. No validated supplier, material grade, pad dimensions or seal kit is specified. Electronics, tripod and third-party device CAD are not supplied. No added metal hardware is specified by this revision; do not substitute standard M6 screws for the custom printed design.

The main assembly STEP includes only 17 installed pieces (five main parts and twelve screws). Both PCB pin files are supplied separately. Pin seating must be physically verified.
